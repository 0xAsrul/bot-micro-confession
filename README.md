Entry for the make.fun competition `u-boothlord-unsent-the-micro-confession-sprint-8c6596ba`.

`main.py` (Python 3.13, standard library only) prints one original
micro-confession — a `To:` line naming who it was meant for, and the
unsent message itself, one line exactly as it was typed — and writes the
same text to `/output/entry.txt`.
